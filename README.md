# Text to Animated Video 🎬

Convierte texto en videos animados de forma **simple y automática**.

## ¿Qué hace?

Toma un texto como entrada y crea un video animado donde:
- El texto aparece con animaciones
- Se puede personalizar colores, velocidad y estilo
- Se exporta como video MP4
- ¡Sin necesidad de saber programación!

## Características

✨ **Fácil de usar** - Interfaz simple e intuitiva
🎨 **Personalizable** - Elige colores, fuentes y estilos
⚡ **Rápido** - Genera videos en segundos
📱 **Web-based** - Funciona en cualquier navegador
🎬 **Múltiples estilos** - Diferentes efectos de animación

## Cómo empezar

### Opción 1: Usar la versión web (más fácil)
1. Ve a la carpeta `web/`
2. Abre `index.html` en tu navegador
3. Escribe tu texto
4. ¡Genera tu video!

### Opción 2: Versión Python (avanzado)
```bash
pip install -r requirements.txt
python app.py
```

## Ejemplos de uso

**Entrada:**
```
Hola mundo
```

**Salida:** Video MP4 con el texto animado
